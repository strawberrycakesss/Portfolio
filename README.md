# Personal Portfolio System

## Files
- `index.html`: Complete self-contained portfolio website.

## How to run
1. Install Node.js and npm.
2. Run `npm run dev` from this folder.
3. Open http://localhost:8000 in a modern web browser.

## Customization
- Replace sample name, school, education, projects, and contact details with your real information.
- Update the email, GitHub, and LinkedIn links before publishing.

## Note
This is a front-end portfolio. The contact form opens a prepared email and does not store submissions in a database.
